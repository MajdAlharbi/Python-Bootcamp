# Python Bootcamp at Tuwaiq Academy

This repository documents my learning journey during the Python Web Development Bootcamp at Tuwaiq Academy.

It includes notes, exercises, assignments, automation scripts, and practical projects completed throughout the program, along with assessments provided by instructors Faisal and Waleed.

## Repository Organization

The repository is organized by week and day. Each folder contains the notes, exercises, assignments, and projects completed during the bootcamp.

## Purpose

The purpose of this repository is to track my progress, document what I learn, and build practical experience in Python and web development.
