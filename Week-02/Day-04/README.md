# Conditions and Input Validation

## Overview

In this lesson, I learned how to control the program flow using conditional statements and validate user input before processing it.

## Topics Covered

- Boolean values (`True` and `False`)
- Comparison operators (`==`, `!=`, `>`, `<`, `>=`, `<=`)
- `if`, `elif`, and `else`
- Nested conditions
- Logical operators (`and`, `or`, `not`)
- Truthy and Falsy values
- Input validation
- String validation methods:
  - `strip()`
  - `isdigit()`
  - `isalpha()`
  - `isalnum()`
- Range and membership validation (`in`)
- Conditional (ternary) expressions
- `match-case` statements
- Common conditional programming mistakes
